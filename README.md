## # 🛠️ 日常更新与推送三步法

打开本地项目文件夹的终端（Git Bash 或 CMD），依次输入以下命令：

1. 暂存修改（把新文件或修改过的文件添加到暂存区）

```bash
 git add . 
```
> 请谨慎使用此类代码。

2. 提交保存（保存本次修改，并写上备注说明）：
```bash
git commit -m "本次更新的描述"
```
> 请谨慎使用此类代码。

3. 推送到云端（直接推送到远程仓库）：
```bash
git push
 ```
> 请谨慎使用此类代码。

## # 换电脑怎么操作
 ### 新电脑上：
  #### # 1. 克隆项目
`git clone https://github.com`

  ## # 2. 配置环境
* 用微信开发者工具导入这个目录，填上你的 AppID
* 菜单 -> 工具 -> 构建 npm （如果有用到 npm 包的话）

  ## # 3. 开始写代码
1. **拉取更新**：`git pull` （每次开始前先拉）
2. **暂存与提交**：
    * `git add .`
    * `git commit -m "在新电脑上的改动"`
3. **推送代码**：`git push` （推回去）

## # 一张速查表
| 操作 | 命令 |
| :--- | :--- |
| 添加远程仓库 | `git remote add origin <URL>` |
| 首次推送 | `git push -u origin master` |
| 以后推送 | `git push` |
| 拉取更新 | `git pull` |
| 暂存改动 | `git add .` |
| 提交 | `git commit -m "本次更新的描述"` |
| 查看状态 | `git status` |
| 查看远程 | `git remote -v` |
